## 2. 上传

后台 → **项目 / Items** → **+ 新建项目（New item）** → 上传 `dist/CAST-1.0.0.zip`。

- 上传 **zip**，不要传 `dist/CAST-1.0.0.crx`（crx 是我们本地自签的测试包；商店用你自己的 zip，签名与 `dist/keys/CAST-1.0.0.pem` 无关）。
- **不要把 `.pem` 打进包里，也不要上传**。它是本地打包私钥，泄露后别人可以伪造更新。

上传成功后进入商品详情编辑页，共四个标签：**商品详情 / 隐私权实务 / 分发 / 测试说明**。

## 3. 商品详情（Store listing）

| 字段 | 填什么 |
|---|---|
| 名称 | `CAST · 随机密码铸造`（13 字符，上限 75） |
| 简短说明 | 见下方，87 字符（上限 132） |
| 类别 | **生产工具 / Productivity** |
| 语言 | 中文（简体） |
| 图标 | `extension/icons/icon128.png` |
| 截图 | `store/screenshots/store-1.png`、`store-2.png`、`store-3.png`（1280×800，最多 5 张） |
| 小宣传图 | `store/screenshots/promo-440x280.png`（可选，但想被推荐位选中就传） |
| 官网 / 支持链接 | 可留空，或填隐私政策页面地址 |

**简短说明（复制这段）：**

```
一键铸一枚真随机密码。大小写、数字、25 个特殊符号逐颗可选，长度 6–64 可调；全部由 Web Crypto 在本机生成，不联网、不上传，复制后 30 秒自动覆盖剪贴板。
```

**详细说明（复制这段，Markdown 不生效，纯文本即可）：**

```
CAST 只做一件事：在弹窗里给你一枚够格的随机密码。

【它怎么生成】
· 随机数来自浏览器的 Web Crypto（crypto.getRandomValues），不是 Math.random；
  取字符时做拒绝采样，避免取模带来的分布偏移。
· 大写、小写、数字三组默认全开，特殊字符 25 颗默认全开，每组至少取一枚。
· 长度 6–64，拖动或用 ←/→ 微调，刻度尺跟着变。

【25 个特殊字符，逐颗可关】
很多站点会拒绝 &  ~  <  >  这类符号。这一版把特殊字符拆成了 25 颗字粒，
点一下关一颗，关掉的符号绝不会出现在生成的密码里。
整行开关是「整组停用 / 原样恢复」——关掉再打开，你挑过的那些还是原样回来，
不会被重置成全部打开。

【当场能看到强度】
顶部实时给出 bit 数、强度等级和暴力破解耗时估算。
改了长度、字盘或任一开关，数字立刻重算。

【看不见的两件事】
· 不联网。清单里没有申请任何主机权限，代码里没有一行发起网络请求的语句，
  没有统计 SDK，没有远程配置。密码只在你本机生成，也只留在本机。
· 复制后 30 秒，剪贴板会被一个不可见的零宽字符覆盖，密码不会长期停在系统剪贴板里。
  （Mac 上「通用剪贴板」会把内容同步到其他设备，这一步尤其必要。）

【历史】
最近 8 枚密码按时间排开，点一下就能复制回来；随时可以一键清空。
数据存在本机的 chrome.storage.local，不跨设备同步。

【权限与理由】
· storage —— 保存你的设置和最多 8 条历史。
· clipboardWrite —— 把你点击「复制」的那枚密码写入剪贴板。
· alarms —— 弹窗关闭后，用 30 秒定时器覆盖剪贴板。
· offscreen —— 创建隐藏页面完成这次覆盖（后台脚本没有剪贴板接口）。
除此之外不申请任何权限，不读取任何网页内容。

隐私权政策：[把你的隐私政策 URL 填在这里]
```

## 4. 隐私权实务（Privacy practices）——审核能不能过看这一页

这一页全是文字，也是最常见的被拒原因。逐项照抄：

### 单一用途说明

```
Generate a cryptographically random password locally inside the extension popup and copy it to the clipboard.
```

（中文备注给自己：弹窗内本地生成一枚密码学随机密码并复制到剪贴板。）

### 权限理由（后台一栏一个，英文更稳）

**storage**
```
Stores the user's generator preferences (length, character sets, per-symbol selection, toggles) and up to 8 recently generated passwords in chrome.storage.local, so the user can copy a previous password again. This data never leaves the device and is not synced or transmitted.
```

**clipboardWrite**
```
Used only when the user presses the Copy button: the generated password is written to the system clipboard. This is the only clipboard write the extension performs.
```

**alarms**
```
Schedules one 30-second timer that overwrites the clipboard after the popup closes, so the generated password does not linger in the system clipboard. The popup's own timer is destroyed when the popup closes, so the timer has to live in the service worker.
```

**offscreen**
```
Creates a hidden offscreen document to perform that clipboard overwrite. A Manifest V3 service worker has no clipboard API, so the write must happen in a DOM context.
```

- 主机权限：无（不需要填）。
- 远程代码：**No**（全部代码在包内）。

### 数据使用声明

所有类别（个人身份信息、健康、财务与付款、身份验证信息、个人通讯、位置、网络浏览记录、用户活动）**全部选「不收集」**。

理由写实在的：

```
The extension does not collect or transmit any user data. Passwords are generated locally with the Web Crypto API and stored only in the browser's local extension storage on the user's device. There are no network requests, no analytics, no remote configuration, and no host permissions.
```

下面三个承诺勾选框（不出售数据 / 不用于无关用途 / 不用于信贷评估）按实际情况勾选——都成立。

### 隐私权政策 URL

需要**公网可访问**的地址。仓库里有现成的 `store/privacy-policy.html`，把它放到任意静态托管即可：

- GitHub Pages：新建仓库 → 上传该文件改名为 `index.html` → Settings → Pages → 选分支 → 得到 `https://<用户名>.github.io/<仓库>/`
- 或者 Notion / 飞书文档 / 腾讯文档公开页（能把上面内容贴进去就行）

> 记得把文件里 `your-email@example.com` 换成你真实可收信的邮箱——审核会核对这一项。

- 地区：全部（或按需勾选）
- 提交后会进入审核。这套配置（4 个常规权限、无主机权限、无远程代码）通常 **1–3 个工作日**；新账号首次提交可能久一些。

## 6. 提审之后

1. 邮箱会收到「已提交审核」，通过后收到「已发布」。
2. 发布后 Chrome 会在几小时内把新版本推给用户；本地测试用的解压版可以删掉，避免和商店版并存打架。
3. **更新流程**：改代码 → `manifest.json` 里版本号必须比上一版大（1.0.0 → 1.0.1，数字逐段比较）→ 重新打包 → 上传新 zip → 提交。新增权限会重新走一遍完整审核。
