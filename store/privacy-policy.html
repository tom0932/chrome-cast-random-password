CAST随机密码铸造

隐私权政策

生效日期：2026 年 11 月 3 日 · 适用版本：1.0.0 及以后

一句话：这个扩展不收集任何数据。密码在你的浏览器里生成，也只留在你的浏览器里。 它没有任何服务器，代码里没有一行发起网络请求的语句。

English summary. CAST does not collect, transmit, sell or share any user data. Passwords are generated locally with the Web Crypto API and stored only in chrome.storage.local on the user's device. The extension makes no network requests, loads no remote code, and requests no host permissions. The only clipboard interaction is the password the user explicitly copies, which is overwritten 30 seconds later with a zero-width character.

一、我们不收集什么

CAST 不收集、不上传、不出售、不共享任何用户数据，包括但不限于：

  • 你生成的密码、长度、字符组合偏好；
  • 你的浏览记录、访问的网址、页面内容；
  • 设备标识符、IP 地址、位置信息；
  • 任何可用于识别你个人身份的信息。

扩展没有分析 SDK、没有崩溃上报、没有远程配置、没有广告。清单文件里没有申请任何主机权限（host_permissions），因此它读取不了任何网页的内容。

二、数据存在哪里

存储位置存了什么删除方式
chrome.storage.local 你的设置（长度、字符组、逐颗符号选择、开关项），以及最近 8 枚密码的明文——只为了让你在同一个浏览器里点一下复制回来。 点「历史」页的「清空铸造记录」，或卸载扩展。
chrome.storage.session 关掉设置里的「关闭弹窗即清空」后，当前这枚密码会临时存在会话内存里，浏览器关闭即消失。 浏览器关闭，或重新打开设置项。

以上数据都留在你本机的 Chrome 配置目录内，不会跨设备同步（扩展未申请 storage.sync），也不会离开这台设备。

三、剪贴板

当你点击「复制」时，密码会被写入系统剪贴板——这是扩展唯一一次接触剪贴板，且由你的点击直接触发。

若设置中的「复制后 30 秒覆盖剪贴板」处于开启状态（默认开启），扩展会在 30 秒后用一个不可见的零宽空格覆盖剪贴板内容，让密码不再停留在系统剪贴板里。这个动作在本地完成，不读取剪贴板里的任何内容，也不会把剪贴板内容发送到任何地方。

四、权限说明

权限用途
storage在本机保存你的设置和最多 8 条历史记录。
clipboardWrite把你点击「复制」的那枚密码写入剪贴板。
alarms弹窗关闭后，用 30 秒的定时器覆盖剪贴板（弹窗里的计时器会随弹窗销毁，所以必须交给后台）。
offscreen创建一个隐藏页面来完成上述剪贴板覆盖动作，因为后台脚本没有剪贴板接口。

除以上四项外，扩展不申请任何其他权限。

五、远程代码与第三方

扩展的全部代码都打包在安装包内，不加载任何远程脚本，不使用 eval()，不引入任何第三方统计或广告库。没有第三方会因为你使用本扩展而获得任何数据。

六、儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集任何人的信息——它对所有人都不收集。

七、政策变更

如果将来某个版本需要处理数据（目前没有这个计划），本页面会在该版本发布前更新，并在扩展的更新说明里明确告知变更内容。
